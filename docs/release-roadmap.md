# Release Roadmap

The authoritative route is V0.1.0 through V5.0.0. A version may advance only after its implementation, regression, runtime, documentation, review and packaging gates pass.

| Major stage | Versions | Completion target |
|---|---|---|
| 1. Engineering foundation | V0.1.0–V0.7.0 | Deterministic streamed world foundation and saves |
| 2. Base game | V0.8.0–V1.0.0 | First complete playable loop |
| 3. World expansion | V1.1.0–V2.0.0 | Rich surface, settlements, caves and dungeons |
| 4. Civilization | V2.1.0–V3.0.0 | NPCs, relationships, quests, factions and events |
| 5. Survival and building | V3.1.0–V4.0.0 | Survival, homes, farming and automation |
| 6. Large world content | V4.1.0–V4.6.0 | Oceans, seasons, cities and endgame |
| 7. Quality and tools | V4.7.0–V4.12.0 | Performance, editors, extensibility and polish |
| Final | V5.0.0 | Complete offline Windows release |
