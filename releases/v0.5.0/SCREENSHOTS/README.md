# V0.5.0 Visual Evidence

`biome-debug-map.png` is generated by `tools/render_biome_map.gd` through the same `TerrainGenerator.biome_at` path used by streamed chunks.

- Image: 384×384 pixels.
- Coverage: 1,536×1,536 world tiles at four world tiles per pixel.
- Origin: `(-768, -768)`.
- Dark guide lines: every 256 world tiles.
- Palette: deep ocean dark blue, ocean blue, coast gold, plains light green, forest dark green, desert orange, snowfield white, swamp olive and mountain gray.

The map was visually inspected for large coherent regions, recognizable climate zones, coast transitions and absence of random single-cell color noise.
