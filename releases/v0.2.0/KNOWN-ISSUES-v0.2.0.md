# V0.2.0 Known Issues

- The movement sandbox is deliberately finite; deterministic terrain begins in V0.3.0 and chunk streaming in V0.4.0.
- Terrain, obstacles and the avatar use code-drawn validation art rather than final production sprites.
- Keyboard input is implemented; controller mapping and rebinding arrive in later control/accessibility iterations.
- The Windows executable is cross-built and PE-validated on Linux. Native Windows runtime verification remains a downstream release task.
