# V0.7.0 Visual Evidence

`save-difference-map.png` is generated by `tools/render_save_diff_map.gd` from generation-v4 chunks and the same `ResourceHarvestState` collected-key layer used after loading a save.

- Image: 512×512 pixels.
- Coverage: 4×4 chunks, or 128×128 world tiles, at four pixels per world tile.
- Origin chunk: `(-2, -5)`.
- Gold guide lines: exact 32×32 chunk borders.
- Colored dots: 668 generated resources still present.
- Red X marks: 75 persisted removals hidden by restored difference keys.
- Background: exact generated biome colors.
- Restored item fixture: wood 12, stone 7 and fiber 4.

The image was visually inspected for removed keys on both sides of chunk borders, unchanged generated background and continued visibility of unmodified resources. File creation, position restore, backup and corruption behavior are verified in the automated suite rather than inferred from the image.
