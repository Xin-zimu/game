# V0.9.0 Visual Evidence

`crafting-progression.png` is a 1280×720 exact-data/layout reconstruction of the V0.9 runtime UI. It shows:

- the hands/workbench/campfire station tabs and recipe-state legend;
- wooden-tool, workstation, stone-tool and food progression;
- exact example material counts and disabled/craftable states;
- the always-visible hotbar with a selected worn stone axe;
- the inventory durability representation and gameplay HUD context.

The image is inspected at original resolution for text rendering, containment, state clarity and overlap. A direct X11 capture is unavailable because the build sandbox blocks local display sockets; runtime scene smoke and UI node/containment tests cover the executable layout path.
