# V0.9.0 Known Issues

- A workbench or campfire enables its recipe tab while the item is in the backpack. World placement and proximity requirements begin with the later building-system versions.
- Wooden and stone swords are craftable, durable inventory items; attacks and enemy damage begin in V0.10.
- Cooked berries are a valid basic-food output but cannot yet be consumed because hunger and food effects belong to the survival-system stage.
- Torches are craftable inventory utilities; held/world lighting behavior is scheduled for later lighting and building work.
- Right-click split uses the first empty slot; an arbitrary destination can be chosen by dragging the resulting stack.
- The release visual is an exact-data/layout reconstruction because the build sandbox blocks local X11 display sockets; runtime node counts, containment and both scenes are still automated.
- The Windows executable is cross-built and PE-validated on Linux. Native Windows runtime verification remains a downstream release task.
