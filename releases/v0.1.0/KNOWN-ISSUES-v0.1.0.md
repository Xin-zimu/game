# V0.1.0 Known Issues

- V0.1.0 is an engineering skeleton, so the game scene intentionally contains no controllable player or generated world.
- Continue Game is intentionally disabled until the V0.7.0 save-system release.
- Pixel-art production assets, sound and music arrive in their scheduled content releases.
- The Windows build is cross-exported on Linux; the equivalent Linux release binary passed the runtime smoke test, while native Windows hardware validation is deferred to a Windows test machine.
