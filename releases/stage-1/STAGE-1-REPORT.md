## 阶段验收

- 工程可从主菜单创建命名世界，并用稳定文字或数字种子进入。
- 玩家可向任意方向移动，区块按半径动态生成、激活、缓存和卸载。
- 相同种子、坐标和 generation version 产生相同地形、群系与资源字节。
- 深水、浅水、海岸、陆地与九类群系跨区块连续。
- 树木、石头、草、花和浆果按群系生成且无严重重叠。
- 工具检查、耐久、正确掉落、32 槽对象池和自动拾取形成基础交互循环。
- 玩家位置、生命、体力、工具、采集计数和已破坏资源在退出后恢复。
- 未修改区块创建 0 个差异文件；损坏存档显示文件、行号和原因。
- 自动保存后台写入，测试夹具主线程派发小于 50 ms，文件任务约 1–2 ms。
- Windows 64 位 PE 与 Linux 64 位 ELF 均由 Godot 4.7.1 release 模板构建；Linux 可启动并报告正确版本。
- 所有运行内容完全离线，不连接 API、云服务或 AI 模型。
